# 字幕工坊 · Subtitle Studio

[简体中文](README.md) | [English](README.en.md) | [日本語](README.ja.md)

Windows 11 x64 向けの、中国語 UI を備えた動画リマックス・字幕処理ツールです。メディア処理はすべてローカルで行います。動画ごとの設定と、複数動画を順番に処理するキューに対応しています。

> 現在は受け入れテスト用のリリース候補版です。主要な処理フローと字幕焼き込みの専用テストは通過していますが、クリーンな Windows 11 環境や実際のディスク容量不足での検証は未完了です。本番の焼き込み前に、画像プレビューと 10 秒の試し出力を確認してください。

## 3 つの機能

| 機能 | 出力 | 処理内容 |
|---|---|---|
| 無劣化リマックス | MKV / MP4 | 選択した映像・音声ストリームを再エンコードせずコピー |
| 字幕の格納（ソフト字幕） | MKV | 複数の ASS / SRT、トラック名、言語、既定トラック、TTF / OTF フォント添付 |
| 高画質字幕焼き込み | MP4 | libass で描画、H.264 CRF 18 / slow。AAC 音声はコピーし、それ以外は AAC に変換 |

トラックの互換性確認、字幕の参照フォント・添付フォントの確認、UTF-8 / UTF-16 / GB18030、画像プレビュー、10 秒の試し出力、進捗表示、キャンセル、ログに対応しています。出力は新しいファイルとして保存し、同名の場合は自動で番号を付けます。一時ファイルの検証後に正式な出力ファイルへ移します。

## 使い方

ランタイムと `engines` フォルダーを含む Windows 配布パッケージをすべて展開し、`SubtitleStudio.exe` を実行してください。開発環境のインストールは不要です。ソースリポジトリ自体には処理エンジンやランタイムは含まれていません。

アプリの UI は現在中国語です。以下では操作ボタンの中国語表記も併記しています。この README の翻訳によって UI の言語が変わるわけではありません。

1. MKV / MP4 をドラッグ＆ドロップし、機能を選びます。
2. 保持するトラックを選択し、字幕やフォントを追加します。焼き込みの場合は字幕と音声をそれぞれ 1 トラック選びます。
3. 字幕の文字とフォントを確認し、出力先フォルダーを選びます。
4. 焼き込みは、画像プレビューと試し出力を確認してから本番処理を始めることをお勧めします。

出力先の横で拡張子を除くファイル名を編集するか、**选择位置和文件名…**（出力先とファイル名を選択）で両方を指定できます。既定名は `元の動画名_output` で、同名の場合は自動で番号を付けます。個別に設定してキューへ追加したジョブは指定した名前を保持し、一括追加では各動画の元の名前を使います。外部字幕とフォントの欄は、字幕格納・焼き込みモードで表示します。

詳しくは [使用説明](docs/使用说明.md) と [受け入れテスト報告](docs/验收报告.md) を参照してください。いずれも現在は中国語です。

### 設定の記憶とバッチ処理

正常終了時、処理開始時、またはキューへの追加時に、機能、出力形式、出力先、SRT のフォント・サイズ・位置を保存します。設定は `%LOCALAPPDATA%/SubtitleStudio/settings.json` に保存され、次回起動時に復元されます。設定ファイルが破損している場合は初期値を使用します。入力ファイル、トラックの選択、字幕・フォントファイルの一覧、キューは次回起動時に引き継ぎません。

- 動画を個別に設定してから **当前配置加入队列**（現在の設定をキューに追加）をクリックします。各ジョブは独立した設定を保持し、リマックス、字幕格納、焼き込みを同じキューに混在させられます。
- 機能と出力先を選び、**批量选择视频…**（動画をまとめて選択）をクリックするか、複数の動画をドラッグ＆ドロップします。一括追加では元のトラックをすべて保持し、既定の音声トラック、現在追加されているフォント、SRT のスタイル設定を使用します。互換性がないトラックは理由を表示します。対象の動画を個別に設定し、そのトラックを選択解除してからキューに追加してください。
- 字幕格納では、同じフォルダー内の、拡張子を除く名前が一致する ASS/SRT を探します。例：`第01話.mp4` に対して `第01話.ass` と `第01話.srt`。焼き込みでは一致する外部字幕が 1 つである必要があります。一致する外部字幕がなければ、動画内の字幕が 1 トラックだけの場合にその字幕を使います。候補を一意に決められない場合は個別設定が必要です。自動追加では UTF-8/UTF-16 を判別します。GB18030 は個別に指定してください。
- **查看任务设置**（ジョブの設定を表示）で確認してから、**开始队列 / 重试未完成**（キュー開始／未完了を再試行）をクリックします。1 件が失敗しても次のジョブへ進みます。キャンセルするとキューを停止し、再試行では完了済みのジョブを飛ばします。出力には自動で番号を付け、元のファイルを上書きしません。
- UI の設定変更は、すでに追加したジョブには反映されません。変更したいジョブはキューから取り除いて追加し直してください。終了時にキューは保存されず、中断したエンコードの途中再開にも対応していません。

### 処理上の制限

- **リマックスでは映像・音声の符号化データを保持します。** コンテナー、ヘッダー、タイムラインの原点は変わる場合があります。AAC の先頭遅延や末尾のトリミングは、コンテナーやプレーヤーによって解釈が異なるため、ファイル全体のハッシュで画質・音質の同一性を判定することはできません。
- **ASS / SRT をそのまま格納する場合は MKV を使用します。** MP4 はこれらの字幕やフォント添付をそのまま保持できません。互換性のないトラックを選択解除するか、MKV に切り替えてください。MP4 の `mov_text` を MKV に移す場合も、字幕形式を自動変換して処理を続けることはありません。
- **字幕焼き込みでは映像を再エンコードします。** 字幕は映像の一部になります。元の解像度とフレームの時刻関係を保持します。現バージョンの焼き込みは SDR のみ対応し、HDR・HLG・Dolby Vision は焼き込み処理の対象外としてブロックします。
- ASS の再生結果は、プレーヤーのスタイル・フォント対応に依存します。PC にインストール済みのフォントが MKV に添付されているとは限りません。
- バッチキューはローカルの動画を 1 件ずつ処理します。字幕エディターや Bilibili への自動投稿機能は含まれません。

## ソースからビルド

Windows x64 と [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) が必要です。

```powershell
dotnet build SubtitleStudio/SubtitleStudio.csproj -c Release
dotnet publish SubtitleStudio/SubtitleStudio.csproj -c Release -r win-x64 --self-contained true -o publish
```

次のプログラムを `publish/engines/` に配置してください。

| ファイル | 検証済みバージョン | 配布元 |
|---|---|---|
| ffmpeg.exe / ffprobe.exe | FFmpeg 9.0.2 essentials、libass / libx264 を含む | [Gyan Windows ビルド](https://www.gyan.dev/ffmpeg/builds/) |
| mkvmerge.exe / mkvextract.exe | MKVToolNix 103.0 x64 | [MKVToolNix](https://mkvtoolnix.download/downloads.html) |

各コンポーネントのライセンスとバージョン情報を保持してください。詳細は [サードパーティーコンポーネント](docs/第三方组件.txt)（中国語）を参照してください。プロセスは `ProcessStartInfo.ArgumentList` で起動し、ファイルパスをシェルに渡しません。

GitHub Actions では Windows のビルドと自己完結型の発行を確認します。動画処理全体の受け入れテストを代替するものではありません。

## 開発とテスト

- [agent.md](agent.md)：プロジェクトの規約、モジュールの役割、検証基準、リリースチェック（中国語）。
- [tests/README.md](tests/README.md)：テスト素材の生成と統合テストの実行（中国語）。
- `MediaEngine.cs`：エンジンプロセス、メディア解析、互換性、文字コード。
- `JobRunner.cs`：ジョブ検証、リマックス、字幕格納、焼き込み、プレビュー、出力検証。
- `SubtitleInspector.cs`：字幕テキスト、ASS の参照フォント、MKV の添付フォント。
- `MainWindow.xaml` / `.cs`：WPF の UI と操作。

テストにはローカルで生成したカラーバー・黒背景の動画と正弦波の音声を使用します。符号化ストリームのコピー、VFR、ゼロ以外の開始時刻、ASS/SRT、プレビューの一致、既定音声、フォント、文字コード、キャンセル、破損した入力を検証します。システムフォントはローカルのテストでのみ使用し、リポジトリには含めません。

不具合報告には、再現手順、処理モード、入力トラック情報、エラーログを添えてください。ログにはローカルパスが含まれるため、共有前に個人情報を取り除いてください。許可のない動画やフォントを公開アップロードしないでください。
