# 验收报告（0.9.0 候选版）

2026-11-14，Windows x64 本机测试。

## 已有证据

- Release 自包含发布成功，零编译错误；包内有 .NET 10.0.15 Core 与 WindowsDesktop 运行库，以及 FFmpeg、FFprobe、mkvmerge、mkvextract。
- 从交付目录启动实际 WPF 窗口，载入中文/空格/& 路径视频，正确显示三条轨道，通过执行前清单确认，完成 MKV 换封装。
- 实际引擎测试 MP4→MKV→MP4。H.264 和双 AAC 编码流哈希一致；视频解码哈希一致。AAC 有效采样逐字节一致，容器转换后的前导/尾部填充有所不同。
- ASS+SRT 多字幕封装，ASS 外部和内部字幕烧录，画面预览、10 秒试输出、完整输出成功。
- 非零起始时间、FLAC→AAC、字体附件保留及加载、VFR 逐帧数量与相对时间戳测试通过。
- HDR(PQ) 检测拦截、GB18030、UTF-16LE/BE、损坏输入、任务取消后无正式文件及临时目录残留、取消后重试通过。
- 预览图人工检查：中文、双行、白字黑边正常。复杂 ASS 样例含颜色、定位、重叠与卡拉 OK。
- 源码旁附可复现的测试项目、素材生成脚本和示例字幕。

## 未完成的验收

- 未在完全未安装 .NET / 开发环境 / 引擎的独立 Windows 11 系统中运行。当前主机没有 Windows Sandbox，不能把本机启动当作干净系统验收。
- 尚未完成独立播放器对开头、中间、结尾的逐项人工核对。
- 磁盘耗尽、杜比视界真实素材以及更广泛编码组合还需补充实际测试。HLG 与 OTF 补充验证见下方记录。
- 已补齐已有字幕与字体附件检查，测试结果见下方补充记录。

因此当前标记为可运行的验收候选版，并非全部计划验收完成。

## 烧录专项补充验收

- 实际界面完成添加 ASS、选择烧录、显示 CRF18/slow 与默认第二 AAC 音轨直接复制、生成 MP4 的全流程。
- 黑底素材逐帧验证了字幕开始前/结束后的空画面、中文双行、底部位置、顶部定位、重叠事件、结尾字幕。
- 卡拉 OK 在 4.25 秒存在 398 个红色字幕像素，5 秒已变成白色，验证逐字颜色随时间变化。
- 0.75、1.5、4.25、5、11 秒的预览与正式输出像素平均绝对差小于 1.5/255（正式输出为有损 H.264）；10 秒试输出首帧与正式输出对应时间一致。
- 默认第二 AAC 音轨及手动第一 AAC 音轨的编码数据哈希均与源音轨一致。
- SRT 顶部位置及字号设置生效；已有 ASS 轨道烧录生效。
- 所有专项输出完整解码无错误；FFplay 独立进程完整播放 12 秒烧录 MP4，正常退出，播放阶段音视频时间差约在一帧内。
- 图像检查覆盖开头、重叠、卡拉 OK、结束时字幕；独立播放器中的全套人工效果验收及干净 Win11 验收仍未完成。

## 字体检查补充验收

已有字幕文字预览、MKV 中字体附件的实际字体名称、ASS 样式和行内字体引用、缺失字体判断已实现并通过实际文件测试。字体检查报告现在区分已携带字体和仅本机安装字体。另已验证 OTF 文件能作为 font/otf 附件封装，尚需补充其烧录加载测试。


## 最新本机补充验证

OTF 附件封装、提取及烧录预览；HLG 标记实际视频的识别和拦截；引擎执行失败后无正式文件和临时残留，均已通过。用户目前没有可用干净 Windows 11 环境，这项验收仍未完成。
