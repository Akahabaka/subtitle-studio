# 字幕工坊使用说明

适用于 Windows 11 x64。完整解压软件包，双击 `SubtitleStudio.exe`。不要只复制这个 exe；同目录的运行库和 engines 文件夹都需要保留。无需安装 .NET、FFmpeg 或 MKVToolNix。

## 开始

1. 选择或拖入一个 MKV / MP4 视频。
2. 选择无损换封装、字幕内封或高画质字幕烧录。
3. 检查轨道、字幕和字体。在窗口底部“输出位置”点击“选择文件夹…”设置保存位置，也可以直接输入路径。
4. 点击“检查并开始处理”，核对清单后执行。原视频不会被覆盖；同名输出自动编号。

## 无损换封装

选择 MKV 或 MP4。列表中勾选需要保留的轨道和附件。音视频直接复制，不重新压缩。容器和文件头会改变，文件大小、时间原点或显示时长可能略有变化。

ASS / SRT 不能原样复制进 MP4，字体附件也不支持。遇到不兼容提示，取消对应轨道或改用 MKV。MP4 文本字幕转 MKV 也不能保证原格式，因此需要取消该轨道；可以另加 ASS / SRT。

AAC 有编码前导及尾部填充，跨容器时播放器对裁剪信息的解释可能不同。这不代表重新编码。不要用整个容器文件的哈希判断画质；测试采用编码流及解码有效内容核对。

## 字幕内封

输出为 MKV，可以添加多份 ASS / SRT，设置名称、语言和一个默认字幕。取消勾选源文件的字幕可移除旧字幕。语言可使用 `zh`、`en`、`ja`、`und` 等语言代码。

ASS 保留脚本样式；添加它使用的 TTF / OTF 字体能提高换电脑播放的一致性。“检查文字及字体”显示所选外部或已有字幕内容与字体引用，并读取 MKV 的字体附件。烧录模式检查下方选中的烧录字幕，其他模式优先检查外部列表选中的字幕。请用支持 ASS 和字体附件的播放器播放。系统已安装字体不等于已随视频封装，分享视频时应添加相应字体文件。

字幕默认自动识别带 BOM 的 UTF-16 或 UTF-8。旧字幕出现编码错误时，在该行选择 GB18030，再检查文字预览。SRT 本身没有完整 ASS 样式系统。

## 高画质字幕烧录

选择一条外部或已有字幕，选择音轨。ASS 使用脚本样式；SRT 可以调整字体、字号和位置。默认 H.264、CRF 18、slow；保留分辨率与帧时间关系。AAC 音频直接复制，其他音频转 AAC。字幕会成为画面的一部分，不能再关闭。

“时间点”以秒为单位，从视频可播放内容起点计算。“预览画面”生成 PNG；“生成 10 秒试输出”从该时间开始生成短片，接近结尾时可能不足 10 秒。预览、试输出、正式输出共用字幕渲染设置。建议先检查开头、中间和结尾，再处理长视频。

首版烧录支持 SDR。检测到 HDR、HLG 或杜比视界时会阻止烧录。无损换封装仍可在容器兼容时使用。

## 进度与错误

处理期间可以取消。取消或失败不会留下正式输出，随后可重试。正式输出生成前会检查轨道、时长和分辨率。磁盘空间不足、损坏文件、字体或引擎错误会显示原因，可导出技术日志。日志含本地文件路径，请在分享前检查。

处理全程在本地运行，不上传视频。B 站投稿请在网站上自行完成。
